霸州晶圆判定系统——Windows 安装说明
====================================

一、推荐部署方式
一座城市选择 1 台 Windows 10/11 或 Windows Server 电脑作为服务器，其他同事不用安装，使用 Chrome 或 Edge 打开服务器网址即可。

二、服务器电脑首次安装
1. 把整个 ZIP 解压到固定目录，例如 D:\霸州晶圆判定系统。不要直接在 ZIP 内运行。
2. 双击“一键启动系统.cmd”。无需互联网，不需要另装 Python 或 Node.js；窗口会保留，异常时查看 startup-diagnostic.txt。
3. 安装成功后，双击“开放局域网访问.bat”，在 Windows 权限提示中选择“是”。此步骤只需做一次。
4. 打开同目录的“访问地址.txt”，把“同事访问”网址发给同事。
5. 在系统页面点“连接配置”，填写数据库地址、端口、库名、只读账号和密码，先测试再保存。

三、以后使用
- 启动：双击“启动系统.bat”。
- 停止：双击“停止系统.bat”。
- 排查：双击“检测连接.bat”，并查看 runtime\server.err.log。
- 服务器必须保持开机、联网且不能休眠；服务器 IP 变化后重新查看“访问地址.txt”。

四、同事电脑
1. 不需要安装本系统。
2. 使用 Chrome 或 Edge 打开管理员提供的网址，例如 http://192.168.1.20:8000/。
3. 同事必须能访问服务器所在网络。

五、跨城市使用
- 推荐：各城市各部署一台，或由公司 IT 通过 VPN、SD-WAN/专线让不同城市能访问服务器内网 IP。
- 不要把 8000 端口直接映射到公网；本系统当前不带账号登录，公网暴露存在数据安全风险。
- 如使用中央 MySQL，服务器还必须能访问数据库的 3306 端口；建议使用仅查询所需表的只读账号。

六、数据与升级
- 参数模板、人工未测试状态和数据库连接配置保存在 backend\data\local.db；Map 模板保存在 backend\data\layout_templates 等 JSON 文件中。
- 升级前先停止系统并备份整个 backend\data 文件夹；不要把旧 data 覆盖到来源不明的电脑。
- 本离线安装包不含打包电脑的 local.db、数据库密码、历史结果或人工未测试状态，避免现场数据外泄。
- 安装包带有初始 Map 模板；上传、重命名、删除后的模板保存在当前安装目录 backend\data 下。

七、校验安装包
使用 PowerShell 执行：Get-FileHash .\安装包.zip -Algorithm SHA256
结果应与同目录 .sha256.txt 文件一致。
